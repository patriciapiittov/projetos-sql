Mais Moda Store - Banco de Dados Relacional

Projeto de banco de dados relacional desenvolvido para gerenciar uma loja de roupas, estruturado em MySQL.

Estrutura do Banco

O banco de dados é estruturado por 4 tabelas principais:

- funcionários: Cadastro da equipe
- Roupas: Cadastro de estoque de peças
- clientes: Cadastro de clientes da loja
- vendas e vendas_produtos: Sistema de pedidos utilizando modelagem N:N com chave primária composta
